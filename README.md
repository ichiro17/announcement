# 公告簽收系統（原型）

校內管理者從台南市教育公告系統（bulletin.tn.edu.tw）挑選需要強制簽收的重要公告，
建立簽收單並指定應簽對象；教職員登入後在系統內確認已讀簽收，管理者可查看每筆
公告的已簽 / 未簽名單，逾期未簽者以紅色標示。

首頁（`/`）不需登入即可瀏覽，顯示目前所有簽收單的標題、對象說明（例如「全校教職員」、
「教務處」，不列出個別姓名）、簽收期限、原始公告連結。實際簽收動作、已簽/未簽名單，
仍須登入才能操作/查看。

## 安裝

```bash
cd bulletin-signoff
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## 執行

```bash
python app.py
```

啟動後開啟瀏覽器 http://127.0.0.1:5000

第一次執行會自動建立資料庫（`instance/bulletin_signoff.db`）與預設管理者帳號：

- 帳號：`admin`
- 密碼：`admin123`

**首次登入會強制要求修改密碼**，請立刻改成只有你自己知道的密碼。

## 基本操作流程

1. 用 `admin` 登入 → 修改密碼。
2. 前往「教職員名冊」→「批次匯入 CSV」，匯入全校教職員名冊
   （可參考 `sample_staff.csv` 的欄位格式：員工編號、姓名、帳號、單位、職稱、Email）。
   新建立的教職員帳號，預設密碼＝員工編號，首次登入同樣會被要求改密碼。
3. 前往「簽收單管理」→「建立新簽收單」，貼上教育局公告連結、填寫摘要與簽收期限，
   用「快速選取」依全校/單位/職稱勾選應簽對象（也可以手動勾選增減個別人員）；
   點快速選取按鈕時會自動帶入「對象說明」欄位，這欄文字會顯示在不需登入的首頁上。
4. 教職員登入後在「待簽收」頁面看到該筆公告，按「我已閱讀，確認簽收」完成簽收。
5. 管理者在「簽收單管理」可看到每筆簽收單的已簽/未簽人數，點進去看詳細名單；
   超過簽收期限仍未簽的會以紅色標示，需要管理者自行線下催辦（系統不會主動發通知）。

## 目前原型範圍以外的事

- 不會自動抓取 bulletin.tn.edu.tw 的公告內容（該站沒有公開 API），簽收單需要管理者
  手動建立並貼上連結。
- 不會主動發送 Email/簡訊通知，教職員需自行登入查看待簽收清單。
- 帳號密碼為系統自建，未串接學校或教育局既有登入系統。
- 這是本機原型，尚未處理正式雲端部署（網域、SSL、正式主機等）。
